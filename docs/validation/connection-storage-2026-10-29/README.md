## 行为边界

拍摄文件完成前仍在缓存，需点击完成或返回时“保存并返回”。Android 10+ 默认相册备份，可在设置关闭；Android 8–9 使用“导出原件”系统保存对话框。相册写入失败时工程内原件保留并显示数量，不报告全部保存成功。

候选超过 96 张仍先按素材/时间取池；选择最多 24 张连接帧。所有启用素材必须参与同一连接分量，单一素材内孤立帧可明确标记为部分完成；不能把完全不相关的视频静默丢掉。两两匹配增加耗时，合成三圈测试约 7 分钟（包含连接、融合），不是手机性能数据。每次连接检查的节点/矩阵保存在工程 `diagnostics/selection-{workId}.json`，可随工程包导出。
