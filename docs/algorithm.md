# 图像算法与边界

1. 普通视频逐帧解码，按时间选候选，最长边限制为 1280；照片按采样解码并处理 EXIF。
2. OpenCV 返回 Laplacian 方差、ORB 数量、曝光截断比例、与上一选中帧的双向验证匹配比例和中位位移。模糊/曝光/纹理不足与重复帧有明确淘汰原因。阈值可配置，但尚未针对真实手持数据集校准。
3. Hamming KNN + 0.75 比例测试 + 双向一致性 + RANSAC 校验。Homography 只用于匹配几何与旋转相机估计，不直接将整张球面当平面拼接。
4. 建立匹配图；拒绝任何不连通输入，不能默默丢掉新补拍而报告成功。旋转相机估计后使用 BundleAdjusterRay；检查数值、焦距和优化结果。第一启用帧将坐标归一化。
5. ERP 每像素形成 `[sin(yaw)cos(pitch), -sin(pitch), cos(yaw)cos(pitch)]` 世界射线，经 `K Rᵀ` 投回源图。相机后方、源图外和边界像素无效。所有重映射均保留独立有效 Mask。
6. 低分辨率曝光增益估计与 GraphCut 接缝；全分辨率重新投影源图，通过多频带金字塔融合。边界并非简单平均。
7. `observed.png` 保存已定位源图足迹，`coverage.png` 保存真正融合且有源图支持的区域。`quality.png` 独立保存由局部梯度能量与曝光截断得到的质量/纹理指标，不能代替覆盖率；无定位的失败输入没有伪造球面位置。
8. 面积使用每行纬度边界 `sin(top)-sin(bottom)` 的积分。180° 只统计中心半球；自定义未定义目标时不报百分比。
9. mono ERP 仅在明确标记下选最佳完整帧；不把不同时刻运动物体平均。

质量图不是感知质量的完整评价：低纹理天空也可能被标黄。当前没有专用动态物体抑制、重影检测或严重平移视差分类器；几何检查不能替代真机视觉质量验收。
