# 图像算法与边界

1. 普通视频逐帧解码，按时间选候选，最长边限制为 1280；照片按采样解码并处理 EXIF。
2. OpenCV 返回 Laplacian 方差、ORB 数量、曝光截断比例、与上一选中帧的双向验证匹配比例和中位位移。模糊/曝光/纹理不足与重复帧有明确淘汰原因。阈值可配置，但尚未针对真实手持数据集校准。
3. Hamming KNN + 0.75 比例测试 + 双向一致性 + RANSAC 校验。Homography 只用于匹配几何与旋转相机估计，不直接将整张球面当平面拼接。
4. 建立匹配图，原生融合拒绝任何不连通输入。0.1.2 的 Worker 在超过 24 张或发生连接失败时，对最多 96 张候选做与融合一致的 ORB/双向匹配/RANSAC 验证，以已验证连接逐步选择最多 24 张；所有启用素材和仍启用的参考帧必须在同一分量。可明确排除同一素材中的孤立帧并标记“部分完成”，不能默默丢掉整个补拍视频后报告成功。超过 96 张候选仍先按素材/时间取池，因此不是无限长序列的解决方案。诊断包保存实际候选节点、连接矩阵和选中节点。旋转相机估计后，用自研的光束法平差（`ray_adjuster.cpp`，基于 OpenCV `LMSolver`）精化，不再使用 OpenCV 的 `BundleAdjusterRay`。后者比较单位射线，这个残差有退化解（焦距趋于无穷时所有射线收敛到光轴），OpenCV 用 √(fᵢf_j) 缩放来抑制，结果在长序列上把焦距估小、全景变宽：模拟器上 24 帧的已知相机测得覆盖率 62%，应为约 28%。新的平差：
   - 最小化对称像素转移误差 `x_j ~ K_j R_jᵀ R_i K_i⁻¹ x_i`，没有退化解；
   - 同一素材（同一镜头）的所有帧共用一个焦距；第 0 个相机的旋转固定，消除整体规范自由度；
   - 初值的旋转先经 SVD 投影到 SO(3)（基于单应性的初值对真实照片并不严格正交）；
   - 用 4 轮 Cauchy 权重 IRLS（尺度为误差中位数的 2 倍）消除 RANSAC 误接受的不重叠图对，然后剔除 3σ 外的匹配再做无权精化（不会让任何相机失去全部匹配）；
   - 每个图对最多取 60 个均匀分布的内点，雅可比只对相关图对做中心差分。
   在 320×240、f=250、24 帧的已知相机上，估计焦距 250.6，yaw 跨度 131.6°（真值 131.8°）。真实 boat 照片的转移误差从 74.9 px 降到 0.93 px。首次成功时记录锚点帧（`anchorFrame`），之后只要该帧仍启用就以它归一化坐标，帧顺序变化或新增批次不会改变全景方向；锚点被禁用时改用第一张帧并在工程中提示。用户参考 yaw 以绕竖直轴旋转整个球面实现（ERP 视频为精确的列循环移位）。
5. ERP 每像素形成 `[sin(yaw)cos(pitch), -sin(pitch), cos(yaw)cos(pitch)]` 世界射线，经 `K Rᵀ` 投回源图。相机后方、源图外和边界像素无效。所有重映射均保留独立有效 Mask。
6. 低分辨率曝光增益估计与 GraphCut 接缝；全分辨率重新投影源图，通过多频带金字塔融合。边界并非简单平均。
7. `observed.png` 保存已定位源图足迹，`coverage.png` 保存真正融合且有源图支持的区域。`quality.png` 独立保存由局部梯度能量与曝光截断得到的质量/纹理指标，不能代替覆盖率；无定位的失败输入没有伪造球面位置。
8. 面积使用每行纬度边界 `sin(top)-sin(bottom)` 的积分。180° 只统计中心半球；自定义未定义目标时不报百分比。
9. mono ERP 仅在明确标记下选最佳完整帧；不把不同时刻运动物体平均。
10. 视觉定位：实时画面缩至最长边 800，与每张关键帧做相同的双向 ORB/RANSAC 验证，取内点最多且 ≥25 的结果。旋转相机下 `H ≈ K_key R_keyᵀ R_q K_q⁻¹`：令 `M = K_key⁻¹ H`，查询焦距 `f_q = |m₃| / mean(|m₁|,|m₂|)`，`M·diag(f_q,f_q,1)` 经 SVD 投影到 SO(3)；与正交矩阵的残差 > 0.25 视为平移/视差/误匹配而拒绝。`R_q = R_key R_rel`，光轴给出 yaw/pitch。叠加图对每个预览像素求世界射线并采样 RGBA 全景，透明处即未拍摄。
11. 补拍推荐：从真实 coverage.png 降采样网格中，选与已覆盖区相邻（保证重叠）且距当前定位方向最近的未覆盖单元；180° 工程只在中心半球内推荐。传感器仅显示俯仰辅助读数，从不作为全景方向。

质量图不是感知质量的完整评价：低纹理天空也可能被标黄。当前没有专用动态物体抑制、重影检测或严重平移视差分类器；几何检查不能替代真机视觉质量验收。
